# GBRM | Geomagnetic Biology Research Module

A reproducible, evidence-first open research workbench exploring geomagnetic field measurements and experimental hypomagnetic biology.

Development occurs in pull requests. The first milestone adds an interactive static dashboard, source ledger, field comparison, and validation tests.

**Important:** This project does not predict health outcomes or establish that current geomagnetic changes cause harm to humans.
